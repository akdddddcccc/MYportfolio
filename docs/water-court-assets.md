# Water Court Basketball — visual provenance

The portfolio entry is a concept study, not a built venue or a museum commission.
The original Art Stage Basketball Court presentation is dated September–November 2022.

- Figma: `test_function`, file `5tIz6mwR7uarGjbtAGxpga`, page [篮球项目, 923:2](https://www.figma.com/design/5tIz6mwR7uarGjbtAGxpga/test_function?node-id=923-2).

- Original assets: 923:235 (ball graphics), 923:250 (perimeter storage), 923:273 (hoop), 923:297 (day court), 923:354 (line studies).
